    How this is different from the hosted demo

    This page fetches two static JSON files — data/index.json (the embedded, chunked corpus) and data/config.json (thresholds and guard rules) — and runs the whole assistant in this tab: no question you type is ever sent anywhere. There is no photo identification or reminders here (both need either network egress or local storage wiring this reference build does not add); type the plant's name instead. See web-static/README.md for the TypeScript source and the cross-language conformance test that keeps it honest against the Python implementation.

    Sprout is an independent, open-source reference implementation (Apache-2.0). The bundled corpus is synthetic and CC0. This is not veterinary or medical advice.
